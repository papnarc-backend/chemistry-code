EXPERIMENTO 02Prévia ilustrativa
01 / ESTUDO DE CASO

O problema

Uma lista de concentrações e sinais pode ser difícil de interpretar sem visualizar a relação entre as variáveis e a faixa de trabalho.

02 / ESTUDO DE CASO

A solução demonstrada

Uma curva fictícia, A = 0,08C + 0,01, transforma uma absorbância informada em uma estimativa de concentração e posiciona o ponto no gráfico.

03 / ESTUDO DE CASO

O resultado do exemplo

Para A = 0,41, o modelo demonstrativo estima 5 mg/L. A curva foi definida para o exemplo; não foi ajustada a medições e não comprova desempenho analítico.

Experimente a ideia.

Uma pequena demonstração para tornar o projeto concreto.

Demonstração interativa
Dados inteiramente fictícios. Modelo: A = 0,08C + 0,01, em que C está em mg/L. A faixa ilustrativa é 0 a 10 mg/L, correspondente a A entre 0,01 e 0,81.
Teste outro valor entre 0,01 e 0,81.

Concentração estimada
5 mg/L

C = (0,41 − 0,01) ÷ 0,08. Estimativa ilustrativa, sem validação experimental.

● Laranja: padrões fictícios. ● Verde: ponto calculado.

Evolução proposta: importar padrões em CSV, ajustar a regressão com Python/pandas e analisar resíduos antes de discutir validação.

Ideia demonstrativa. Um repositório próprio ainda não foi associado a este projeto.
