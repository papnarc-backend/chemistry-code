# Publicar o Chemistry Code no GitHub Pages

## 1. Criar o repositório

Entre na conta `papnarc-backend` e abra https://github.com/new.

- Nome: `chemistry-code`.
- Descrição sugerida: `Portfólio de estudos em ADS e Química, com LabDilui funcional e projetos demonstrativos.`
- Visibilidade: **Public**.
- Clique em **Create repository**.

Use um repositório próprio para o portfólio. O repositório `LabDilui` continua sendo o projeto independente da calculadora.

## 2. Enviar os arquivos

Extraia `Chemistry-Code-GitHub-Pages.zip`. Abra a pasta extraída e entre nela até encontrar `index.html`, `assets` e `projetos`.

No repositório, escolha **uploading an existing file** ou **Add file → Upload files**. Arraste o conteúdo dessa pasta para a página, preservando as pastas. Não envie o ZIP nem uma pasta externa contendo tudo.

Antes de confirmar, confira se `index.html` ficará na raiz do repositório, ao lado de `README.md`, `assets` e `projetos`.

Mensagem sugerida: `Adicionar portfólio Chemistry Code`. Clique em **Commit changes**.

## 3. Ativar a hospedagem

Abra **Settings → Pages**.

- Em **Source**, selecione **Deploy from a branch**.
- Em **Branch**, escolha **main**.
- Escolha a pasta **/ (root)**.
- Clique em **Save**.

Se `main` não aparecer, conclua o envio dos arquivos primeiro e recarregue a página.

## 4. Conferir o endereço

A publicação pode levar até dez minutos. Em **Settings → Pages**, aguarde a confirmação e clique em **Visit site**.

Se o nome do repositório for exatamente `chemistry-code`, o endereço esperado é:

`https://papnarc-backend.github.io/chemistry-code/`

Esse é um endereço previsto; considere a publicação concluída somente quando **Visit site** abrir o portfólio.

Teste em janela anônima: página inicial, filtros de área, busca, menu no celular, página do LabDilui e cálculo com resultado de **10 mL**. Confira também os links de retorno e o repositório da calculadora.

## 5. Atualizar o LabDilui e compartilhar

O pacote `LabDilui-GitHub.zip` contém o README revisado. No repositório `LabDilui`, substitua o `README.md` pela versão nova e confirme o commit.

Use no LinkedIn o endereço copiado de **Visit site**, após conferir que funciona. O texto de apresentação pode destacar o projeto e os aprendizados sem afirmar que todos os projetos já estão implementados.
